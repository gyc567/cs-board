## 1. 这个工具到底是做什么的

**白板声画工坊**是一个运行在你电脑上的"AI 视频制作工厂"。

你给它三样东西：
- 一段你自己的参考音频（用来克隆你的声音）
- 一段中文文字（你想表达的内容）
- 一个你喜欢的视觉风格

它就能自动帮你生成一段**带有手绘动画和配音的 MP4 视频**：

```
参考音频 + 中文文案 + 视觉风格
            ↓
   音色克隆 → 内容拆解 → 生成插画
            ↓
       手绘动画渲染
            ↓
       配音 + 字幕 + 合成
            ↓
        MP4 成片
```

**关键特点：**
- 🎙️ **音色克隆** — 用你自己的声音读文案，不需要请配音员
- 🎨 **12 种视觉风格** — 从简约白板到国风卡通到赛博霓虹
- 📊 **动态信息图** — 边讲边出现内容，像 PPT 一样配合语音节奏
- 🖥️ **本地运行** — 所有素材和任务都在你自己的电脑上，不上传到云端
- 🔄 **断点续命** — 中途退出、调整参数，已完成的部分不会丢失

## 2. 工作原理：就像拍电影一样

把这个工具想象成一个小型的**视频制作流水线**。每一步都像电影制作的一个部门：

```
┌─────────────────────────────────────────────────────────────┐
│                      参考音频                                 │
│               （你自己的 10~30 秒录音）                        │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│  ① 音色克隆部门                                              │
│  把参考音频发送给本地的 IndexTTS 服务，克隆音色                  │
│  （参考音频永远不离开你的电脑）                                  │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│  ② 脚本拆解部门（AI）                                         │
│  用 GPT 读你的文案，拆成若干"分镜"——                            │
│  就像剧本里的场景描述，每段一个画面                               │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│  ③ 插画生成部门（AI）                                         │
│  用图片生成模型，按分镜描述画出每一张插画                         │
│  风格必须统一，就像同一画师画的                                  │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│  ④ 动画渲染部门                                               │
│  把静态插画变成"手绘动画"：                                     │
│  笔尖一笔一笔地画出线条，像真人在黑板上画一样                      │
│  画面随配音同步播放                                             │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│  ⑤ 合成输出部门                                               │
│  克隆音色朗读文案 + 字幕 + 动画 = MP4 成片                      │
└──────────────────────────────────────────────────────────────┘
```

## 3. 准备工作：你需要准备什么

### 3.1 硬件要求

| 项目 | 最低要求 | 推荐 |
|------|---------|------|
| 操作系统 | Windows 10+ / macOS 13+ | macOS 15+（视频渲染更稳） |
| 内存 | 8 GB | 16 GB+ |
| 显卡 | 无硬性要求 | 有独立显卡（生成图片更快） |
| 硬盘 | 10 GB 可用空间 | SSD |

### 3.2 软件依赖

| 软件 | 版本要求 | 说明 |
|------|---------|------|
| Python | ≥ 3.11 | 运行环境 |
| Node.js | ≥ 22.13 | 前端构建 |
| FFmpeg | 任意版本 | 音视频处理，必须加入 PATH |
| IndexTTS（可选） | 2.5 | 本地音色克隆服务 |

**检查 FFmpeg 是否可用**（终端/命令提示符下运行）：

```bash
# macOS / Linux
ffmpeg -version

# Windows PowerShell
ffmpeg -version
```

如果没有输出，说明 FFmpeg 没装或没加 PATH：[FFmpeg 官方下载](https://ffmpeg.org/download.html)（Windows 推荐用 `winget install ffmpeg`，macOS 推荐 `brew install ffmpeg`）。

### 3.3 API 密钥

这个工具依赖两个外部 AI 服务：

**① OpenLux（文本 + 图片生成）**
- 申请地址：访问 https://openlux.ai 注册
- 需要：文本模型调用权限 + 图片模型调用权限
- 费用：按实际用量计费（图片生成是主要成本）

**② IndexTTS（可选，本地音色克隆）**
- 需要自己部署或使用第三方托管的 IndexTTS 2.5 服务
- 如果不用音色克隆，可以跳过（系统会用默认音色朗读）

## 4. 安装：一键启动

### 4.1 下载项目

```bash
git clone https://github.com/gyc567/cs-board.git
cd cs-board
```

或者直接下载 ZIP 包解压。

### 4.2 Windows（PowerShell）

```powershell
# 第一次：安装依赖（只需运行一次）
python scripts\prepare_env.py
.\.venv\Scripts\python.exe -m pip install -r webapp\requirements.txt
cd web
npm ci
cd ..

# 启动工作台
.\start-webapp.ps1
```

### 4.3 macOS / Linux（终端）

```bash
# 第一次：安装依赖（只需运行一次）
python3.13 scripts/prepare_env.py
./.venv/bin/python -m pip install -r webapp/requirements.txt
cd web && npm ci && cd ..

# 启动工作台
./start-webapp.sh
```

> 💡 **国内网络安装 Python 依赖较慢？** 可以临时使用清华 PyPI 镜像：
> ```bash
> PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple python3.13 scripts/prepare_env.py
> PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple .venv/bin/python -m pip install -r webapp/requirements.txt
> ```

### 4.4 启动成功了吗？

脚本运行后，自动打开浏览器访问 **http://127.0.0.1:13000/**，看到工作台界面即表示启动成功。

同一局域网的手机/其他电脑也可以通过显示的地址访问共享工作台。

## 5. 第一次配置：填好 API 密钥

启动后，点击右上角 **「API 设置」**，依次填写：

### 5.1 OpenLux 配置

| 字段 | 填写内容 |
|------|---------|
| **API Key** | 你在 openlux.ai 申请密钥 |
| **文本模型** | 默认 `gpt-5`（用于拆解文案） |
| **图片模型** | 默认 `gpt-image-2`（用于生成插画） |
| **图片 API 地址**（可选） | 如果图片和文本用不同服务商，单独填 |
| **图片 API Key**（可选） | 同上 |

> ⚠️ 密钥只保存在本机 `.webapp/config.json`，页面不会回显完整密钥。

### 5.2 音色克隆配置（可选）

| 字段 | 填写内容 |
|------|---------|
| **IndexTTS 地址** | `http://127.0.0.1:7860`（Gradio）或 `8000` 端口（FastAPI） |
| **接口类型** | Gradio 或 FastAPI |

### 5.3 测试连接

填完后点「测试」，出现 ✅ 即表示配置成功。

## 6. 制作你的第一支视频：标准模式

下面以**标准制作**模式为例，手把手走完整个流程。

### Step 1：上传参考音频

在「参考音频」区域上传一段 **10~30 秒、单人、噪声较少**的录音。

建议内容："大家好，今天我来分享一个关于猴子与香蕉的故事……"

> 💡 音频质量直接影响克隆效果。尽量：
> - 背景安静，无音乐或噪声
> - 单人说话，语速正常
> - 尽量覆盖多种语调（陈述句、疑问句）

### Step 2：粘贴文案

在「中文文案」框粘贴你想做成视频的文字，至少 10 个字。

### Step 3：选择制作模式

选 **「标准制作」**。

### Step 4：选择视觉模板

从 12 个模板中选一个。新手推荐从「极简粗线简笔白板风」开始——线条干净、颜色简单，最容易上手。

### Step 5：点击开始

点「开始制作」，工作台会依次完成：

```
[1/6] 音色克隆       → 克隆你的声音
[2/6] 拆解文案       → AI 分析结构，生成"分镜脚本"
[3/6] 生成插画       → 为每个分镜生成一张统一风格的插画
[4/6] 渲染动画       → 把插画变成手绘动画（这个最慢）
[5/6] 合成配音       → 克隆音色朗读文案
[6/6] 生成字幕 & 导出 MP4
```

完成后，点击预览观看，满意后点「下载」。

## 7. 三种制作模式怎么选

| 模式 | 什么时候用 | 工作方式 |
|------|-----------|---------|
| **标准制作** | 知识讲解、故事口播、课程宣传 | 自动拆分分镜，生成统一风格插画 + 白板动画 |
| **自定义参考** | 固定 IP、品牌视频、系列内容 | 上传风格图 + 角色参考，让画风与角色贯穿全片 |
| **动态信息图** | 观点表达、商业分析、课程内容 | 先对齐语音时间，再按真实节奏呈现内容卡片 |

**选错了可以改吗？** 可以中途停止某个任务，调整参数后继续，不需要从头来。

## 9. 进阶：自定义参考图片和角色

如果做系列内容（比如品牌视频、IP 动画），想让画风一致，可以用**自定义参考**模式：

### 9.1 上传风格参考图

上传**一张**风格参考图（比如你喜欢的插画风格），系统会让所有分镜都保持这个风格。

### 9.2 添加角色参考

最多可以添加 **5 个角色**，每人上传 **1~3 张**不同角度的参考图。

> ⚠️ 重要说明：系统会**按文案安排角色**，但**不会直接复制参考图里的人脸或动作**。角色会以新的构图和动作出现在画面中，保持风格一致的同时避免侵权问题。

### 9.3 风格统一的关键

在「统一出图规范」里，系统会自动加上以下约束（你不需要手动写）：

- 所有图片使用同一套线条语言和配色
- 人物和物体有统一的比例和画法
- 背景和材质风格一致

## 10. 进阶：动态信息图模式

这是最"聪明"的模式。普通模式下，文案拆解后，画面和配音是分别独立的；而**动态信息图**模式会：

1. **先用真实语音生成时间表** — 把你的配音按真实时间切成短语，并记录每个字在音频里的起止时间
2. **按语音节奏生成内容卡片** — 文字和图表元素会在对应语音开始时才出现，不会"抢跑"
3. **可审查每一步产物** — 时间表、内容结构、页面规格都有独立的 JSON 文件，可以人工核对

> 📄 详细原理见 [`docs/semantic-timing-contract.md`](docs/semantic-timing-contract.md)。

### 使用动态信息图的正确姿势

1. 准备一段你自己朗读的音频（最好是用克隆音色生成后的配音文件）
2. 粘贴完整文案，选择「动态信息图」模式
3. 系统会自动将音频和文案对齐，生成精确到毫秒的时间表
4. 审核时间表，确认每页内容与语音对应关系正确
5. 逐页生成插图，最终渲染成 MP4

## 11. 任务文件在哪里

所有工作都在你本地 `.webapp/` 目录：

```
.webapp/
├── config.json          ← 你的 API 密钥配置（不要分享！）
├── preferences.json      ← 界面偏好设置
└── jobs/
    └── <任务ID>/
        ├── audio.wav         ← 参考音频
        ├── script.json       ← 分镜脚本
        ├── scenes/           ← 每张插画
        │   ├── scene-01.png
        │   └── scene-01.annotation.json
        ├── boards.json       ← 图片生成提示词
        ├── voice.wav         ← 克隆后的配音
        ├── final.mp4         ← 最终成片
        └── metadata.json      ← 任务元数据
```

> 🔒 **安全提醒**：`.webapp/` 目录和其中的音频、密钥文件都在 `.gitignore` 中，不会被提交到 Git。但请勿将任务目录、API 密钥截图发到网上。

## 12. 常见问题与解决方案

### Q1：启动脚本报错 "command not found"

确保进入了项目根目录：
```bash
cd cs-board   # Windows 用 cd cs-board
./start-webapp.sh   # Windows 用 .\start-webapp.ps1
```

### Q2：npm ci 报网络错误（国内）

临时使用淘宝镜像：
```bash
npm config set registry https://registry.npmmirror.com
cd web && npm ci
```

### Q3：API 测试失败

1. 检查 API Key 是否填写正确（注意没有多余空格）
2. 检查网络能否访问 `api.openlux.ai`
3. 确认 API Key 有文本和图片两种权限

### Q4：图片生成很慢

- 没有独立显卡：每次只生成一张图，批量生成会排队
- 图片模型响应时间通常 10~30 秒/张，属正常范围
- 可以减少分镜数量（文案短一些）

### Q5：渲染动画报错 "No module named 'cv2'"

运行一次环境准备脚本：
```bash
python scripts/prepare_env.py
```

### Q6：视频导出后画面和声音对不上

动态信息图模式依赖准确的音频时间对齐。如果时间偏差明显，检查：
1. 参考音频是否清晰、噪声少
2. Whisper.cpp 模型是否正确加载

### Q7：任务中断了，能继续吗？

**可以。** 每个步骤都有检查点（checkpoint）。重新启动工作台，任务会从最后一个完成的步骤继续，不会从头生成。

### Q8：如何修改已完成的某个分镜画面？

在 `.webapp/jobs/<任务ID>/scenes/` 里找到对应图片和 `.annotation.json` 文件，用任何图片编辑器修改 PNG，然后重新渲染那一幕即可，不需要重新生成所有图片。
